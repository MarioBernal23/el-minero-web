# El Minero de la Web

Proyecto de web mining desarrollado en Python.

## Objetivo

Extraer información de páginas web, almacenarla en una base de datos y
analizarla para descubrir patrones mediante técnicas de minería de datos
y machine learning.

## Tecnologías

- Python
- PostgreSQL
- SQLAlchemy
- asyncio
- BeautifulSoup
- pandas
- scikit-learn
- FastAPI

## Arquitectura

El proyecto se divide en cuatro partes principales:

- `extractor/`: extracción de datos de la web.
- `database/`: almacenamiento y acceso a los datos.
- `mining/`: análisis y minería de datos.
- `api/`: API para consultar los resultados.
